## 三、待确认项

### 1. 时钟源公差与器件类型冲突（已关闭）

主控恢复外置驱动器 V2.10 同款 `CSTNE8M00G52A000R0`
（8MHz、内置 10pF、SMD3213-3P）。Y1 pin1→OSCIN(E1)，pin3→OSCOUT(F1)，
pin2→GND。该器件自带负载电容，不再另加 10pF。CAN FD 位时序仍需按最终
时钟源和 PCB 走线实测整定。

### 2. ★ MCU 引脚表的 TIMER7 通道标注与 datasheet 不一致（需固件确认）

QS03 硬件框图明确列出 `PC8(F6) = CH2`、`PA11(C8) = CH0`、`PA12(B8) = CH1`，
并保留 `PC0(E2)/PC2(D3)/PC1(C3)` 作为互补 EN 控制。原理图按这组球位绘制；
固件的 TIMER7 通道映射仍必须确认，否则 PWM 相序和互补关系会错。

### 3. 三相电流采样端接网络（已按 QS03 框图关闭）

说明书 §3.4.1 写“SA/SB/SC 为采样输入……每相一组上/下臂分压电阻”。
MP6543H datasheet 的实际定义是：`SA/SB/SC` 是**三相输出**，
`SOA/SOB/SOC` 才是电流采样输出，端接电阻接在 SOx 上。
本图纸按 datasheet 把 6 只 8.06k 端接在 SOA/SOB/SOC；
并保留 3 只 100Ω + 100pF 滤波。硬件说明书中的 SA/SB/SC 表述仍需同步修正。

### 4. 母线 TVS（已关闭）

按 QS03 硬件框图和 QS01 EBOM，母线 TVS 改为 D3 = SMF16CA
（SOD-123FL，16V，200W，双向）。原 SMCJ18A 方案已删除。

### 5. 地分区方案需确认

文档没有定义分区地，但 §10.4 要求按类型标注。本工程采用
PGND（功率）/ AGND（采样与模拟参考）/ GND（数字）三个网络，
在 POWER 页用 3 只 0Ω（R8/R9/R10）单点星形汇合。
若结构上就是整块地平面，可改为单一 GND 并删掉 3 只 0Ω；
若坚持分区，需在 PCB 上落实同样的单点连接。

### 6. OVP / LVP 阈值（固件侧）

硬件分压固定为 1/11。QS03 硬件框图 V1.1 给出 LVP 默认 5V（4~11V 可调）、
OVP 默认 14V（8~15V 可调）、迟滞 ≥0.3V、去抖 ≥0.5s；最终固件阈值仍需确认。

### 7. 尚未确定料号的元件

| 位号 | 规格 | 说明 |
| --- | --- | --- |
| C7 | 10µF/10V X7R 0603 | U5 输出电容；C8 已删除 |
| R3 | 301k 1% | 使能分压 |
| R4 / R5 | 31.6k / 10.2k 1% 0201 | 反馈分压 |
| R26-R31 | 8.06k 1% ×6 | 三相采样端接（QS01 EBOM） |
| R23-R25 | 100Ω 1% ×3 | 三相采样串阻 |

### 8. 状态灯口径冲突（已按引脚表处理）

§3.9 前后矛盾：一处写“取消全部状态 LED”，另一处写“保留 1 个运行状态 LED”；
而表 27 的“取消状态灯”一行明确 PB14 释放为备用 GPIO。
本图纸按表 27 执行：**不设状态灯**，PB14 置 no-connect。
若最终要保留运行灯，需要改 PB14 并新增 LED + 限流电阻。

### 9. 一维力传感器前端未定

PB6/PB7 作为差分模拟输入预留，前端（仪表放大器或分压）取决于传感器选型。
当前只在 TOP 页放了 2 个测试点（TP4/TP5），MCU 页引出 FORCE_P/FORCE_N 端口，
后续加子页时直接接到该端口即可。

### 10. V3P3 作为模拟 3.3V 的噪声风险

§3.1 表 9 的“方案二”把 MP6543H 内部 LDO 的 V3P3 经磁珠供 VDDA/VREFP，
代价是把功率级本地地噪声带进 MCU 模拟域。图纸按此实现并标注，
但需要在样机上实测 ADC 零点噪声；若超标则改为独立 LDO 供模拟 3.3V。

## 四、可复现性

```powershell
# 重建全部图纸
python .\scripts\build_all.py

# 一键校验并导出
pwsh -NoProfile -File .\scripts\validate.ps1
```

`build_all.py` 会依次重建符号库（工程库 + 分类库 + datasheet 自建符号）、
工程容器与 6 张图纸；`validate.ps1` 负责 upgrade / ERC / 几何审计 /
PDF 文字越界检查 / 网表 / BOM / PDF 导出。
禁止直接手工修改 `.kicad_sch`，所有改动必须回写到 `scripts/`。
