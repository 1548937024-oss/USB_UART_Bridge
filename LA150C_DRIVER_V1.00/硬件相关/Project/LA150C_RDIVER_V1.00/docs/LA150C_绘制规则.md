# LA150C RDIVER V1.00 原理图绘制规则

来源：外置驱动器 MicroDriver V2.10 的绘制经验（`docs/V2.10_绘制规则.md`），
结合《LA150C 集成驱动器硬件概要设计说明书 V1.2》与器件 datasheet 核对结果。
本工程全部原理图由 `scripts/` 下的生成器产出，禁止手工改 `.kicad_sch`。

## 一、电气检查（ERC）硬性规则

1. **一条网络只放一个 `PWR_FLAG`。**
   同一网络上出现两个 `power_out` 引脚会直接报 `pin_to_pin` 错误。
   LA150C 的分配：`VBUS` / `GND` 在 TOP 页（J2 处）声明，
   `PGND` / `AGND` 在 POWER 页声明，`PWR_3V3A` 在 MOTOR 页声明；
   `PWR_3V3` 由 SCT2230MLUAR 的 VOUT(`power_out`) 驱动，不再放旗标。

2. **支线搭干线必须画节点（junction）。**
   走线端点落在另一条走线中间时，KiCad 不认电气连通，会误报
   `pin_not_connected`。`kicad_lib.Sheet.audit()` 已同时检查“引脚落在走线中段”
   与“走线端点落在走线中段”两种情况。

3. **电源输入网络要有驱动源。**
   经过无源器件（磁珠、0Ω 等）之后的网络不再有 `power_out`，
   必须补 `PWR_FLAG`——LA150C 的 `PWR_3V3A` 就是这种情况。

4. **导入器件的引脚类型要归一化。**
   分类库导入的两端保护/无源器件引脚统一改为 `passive`，避免
   `Unspecified 与 Passive 引脚相连` 警告。

5. **`#PWRxx` 参考号必须唯一。**
   同一页里混用“固定编号”和“递增计数”两套编号会撞号，KiCad 会报
   “原理图存在批注错误”，但 ERC 仍然是 0——2026-10-04 的 POWER 页踩过一次。
   现在每页只用一个递增计数器。

## 二、落线与坐标规则

6. **落线前先探测真实引脚坐标，不要靠推算。**
   用 `Sheet.pin()` 读取符号定义并按 `(x, y, rotation, mirror)` 变换。
   KiCad 的 `(mirror x)` 是绕符号自身 x 轴翻转，叠加原理图向下 y 轴后
   等价于取反局部 x——这一点是用一次 ERC 实测校正的，不能靠直觉。

7. **一切对象落在 1.27 mm 栅格上。**
   器件原点、引脚、走线端点、节点、标号锚点、no-connect 都要整格。

8. **器件旋转按电路语义定，不做统一朝向。**
   二端器件按电流方向和自然走线旋转；D3/DE5VS06BA 按纵向支路旋转 90°。

## 三、版面与语义规则

9. **电源在上、地在下的方向感要守住，且电源符号的 Value 必须显示。**
   电源符号放在所辖电路的左上方，GND/PGND/AGND 放在下方；
   所有电源/地符号的 Value 统一放在符号本体右侧、贴着引脚高度，
   不得压在符号图形上（`PWR_FLAG` 例外，它不是电源轨名，Value 保持隐藏）。
   此项覆盖通用规则里的“电源符号 Value 隐藏”。
   局部去耦电容下方直接接地的，允许地符号贴着电容，但仍在其下方。

10. **跨区域连接优先用标签，同区域用短实线。**
   MOTOR 页把 `SOx_RAW` / `nFAULT` / `V3P3_DRV` / `VCP_DRV` 从 U4 引脚引出短桩后
    用同名网络标签接到辅助电路，避免长走线穿过器件本体。

11. **走线不得穿过器件本体。**
    `scripts/verify_sheets.py` 用几何方法逐页检查：
    器件本体是否越出 A4 图框、器件本体是否互相重叠、走线是否穿过本体、
    走线/标号/文字是否落进图框标题栏区域，以及 Reference/Value/注释
    文字框是否互相重叠。ERC 查不出这几类问题。

12. **未使用引脚必须放 no-connect。**
    MT6701 的 U/V/W、PUSH、OUT、NC；GD32F503 的全部未用 GPIO；
    MP6543H 的 N/C(19) 都显式标注。

13. **接口类器件两边都要说清楚。**
    MT6701 的 MODE 必须标注“接 VDD = SSI”，因为它误接地会静默切到 ABZ；
    CAN 的 STB 必须标注“接 GND = 正常工作模式”。

14. **右下角标题栏区域（x ≥ 108 mm，y ≥ 165 mm）不得放图面内容。**
    `AD_Style_A4.kicad_wks` 自带修订表与工程标题栏，测试点、注释、器件压上去
    会与其文字重叠。2026-10-04 的 TOP / MCU 页踩过一次，现在由
    `verify_sheets.py` 强制拦截。

15. **器件属性文字要有间距。**
    5.08 mm 间距排列的阻容会让 Reference / Value 文字贴在一起；
    去耦电容行统一用 7.62 mm 间距。

16. **元器件 Reference / Value 放在器件上方。**
    两行水平排列、左对齐，Reference 在上、Value 在下，基准是
    “本体图形 + 引脚端点”的外包框，因此既不会压到本体，也不会压到引脚。
    测试点只显示位号，Value（TP0.8）隐藏。

17. **图纸模板用 AD 图框 + 紧凑工程标题栏。**
    `AD_Style_A4.kicad_wks` 由 `scripts/build_sheet_template.py` 生成：
    保留完整 AD 双线图框、1-6 / A-D 分区标记和四角折页标记；
    右下角标题栏使用 110 × 24 mm 紧凑工程栏，字段为
    Title / Subtitle / Rev / Date / Sheet / Size。
    完整 AD 标题栏备份在 `AD_Style_A4_full.kicad_wks`。

## 四、与数据手册的核对纪律

14. **文档与 datasheet 冲突时以 datasheet 为准，并在图上留痕。**
    本工程记录了三处冲突（见 `LA150C_设计说明与待确认项.md`）：
    电流采样电阻接 SA/SB/SC 还是 SOA/SOB/SOC、
    MCU 引脚表的 TIMER7 通道标注、以及晶振 ±10 ppm 与陶瓷谐振器的矛盾。
    这些都在对应页面上写了注记，不能只在口头说明。

15. **每次改生成器都要重跑闭环**：
    生成 → `kicad-cli sch upgrade --force` → ERC →
    `verify_sheets.py` → 导出网表/BOM/PDF → 复核。

## 五、工具链

| `scripts/validate.ps1` | 一键跑完上述全部检查并导出产物 |
