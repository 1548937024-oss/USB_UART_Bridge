# PCB Design Specification

本规范适用于 `USB_UART_Bridge` 2 层原型板。制造能力参考嘉立创公开工艺页面，
载流和回流设计参考 IPC-2152、IPC-2221B 及相关 IPC 设计原则。

机器可读规则源：`pcb_design_rules.yaml`

## 1. 制造基线

| 项目 | 项目设计值 | 嘉立创公开能力 |
| --- | --- | --- |
| 层数 | 2 | 1-32 |
| 板厚 | 1.6 mm | 0.4-4.5 mm，1.6 mm 为标准值 |
| 板厚公差 | +/-10% | 厚度 >= 1.0 mm 时 +/-10% |
| 外层铜厚 | 1 oz | 2 层支持 1/2/2.5/3.5/4.5 oz |
| 表面处理 | 无铅 HASL | 支持无铅 HASL、ENIG、OSP |
| 阻焊 | LPI | 绿/紫/红/黄/蓝/白/黑 |
| 最小线宽 | 0.20 mm | 0.15 mm |
| 最小间距 | 0.20 mm | 0.15 mm |
| 最小钻孔 | 0.30 mm | 0.15 mm，但 0.15 mm 成本更高 |
| Via 孔/盘 | 0.30/0.60 mm | 最小 0.15/0.25 mm |
| PTH 环宽 | 0.15 mm 板级下限 | 最小 0.18 mm；0.15 mm 为项目 DFM 例外 |
| 铜到板边 | 0.40 mm | >=0.20 mm |
| 焊盘到丝印 | 0.15 mm | >=0.15 mm |
| 非金属化槽 | 1.00 mm | >=1.00 mm |
| 金属化槽 | 不使用 | >=0.50 mm |
| 孔位置公差 | 0.05 mm | +/-0.05 mm |
| 外形公差 | 0.20 mm | 常规 CNC +/-0.20 mm |
| 盲埋孔 | 不使用 | 不支持 |

上述能力来自嘉立创公开页面，采购前仍需根据最终板框、拼板和工艺选项复核。
PCB 输出坐标以 A4 横向图框中心为基准，整板平移到图框中央；板内器件、开槽和
布线相对坐标不因页面居中而改变。

## 2. 载流设计

载流以 IPC-2152 为主要依据，IPC-2221B 作为通用设计参考。默认假设为 1 oz
铜、10 摄氏度温升、25 摄氏度环境、外层走线和 20% 成品线宽公差。

下表是项目保守设计目标，不替代 IPC-2152 曲线或正式计算工具：

| 电流 | 外层最小线宽目标 |
| --- | --- |
| <=0.10 A | 0.20 mm |
| 0.25 A | 0.25 mm |
| 0.50 A | 0.40 mm |
| 1.00 A | 0.65 mm |
| 2.00 A | 1.20 mm |
| 3.00 A | 1.80 mm |

本项目的附加规则：

- `PWR_5V_USB` 和 `PWR_3V3_USB` 主路径按至少 `0.50 mm` 设计。
- `PWR_5V_ISO` 和 `PWR_3V3_ISO` 按至少 `0.40 mm` 设计。
- 隔离输出 100 mA 以内的局部支路可使用 `0.30 mm`。
- 单个电源过孔不得承担 0.50 A 以上电流，优先使用过孔阵列。
- 最终线宽必须考虑成品线宽公差和铜皮载流能力。

## 3. 回流路径

- USB D+/D- 应参考连续 GND 平面，不得跨越平面开槽或隔离带。
- USB 差分对换层时，信号过孔附近应布置返回过孔，目标距离不超过 `5 mm`。
- 去耦电容到 IC 电源和地引脚的回路面积应尽量小。
- 电源回路应从源端到负载端连续返回，不得跨隔离区借用回流路径。
- `GND` 和 `ISO_GND` 不得共用铜皮、返回过孔或参考平面。
- 铺铜后删除无法可靠连接的小铜岛，不把孤立铜岛当作回流路径。

## 4. 隔离与间距

- 隔离目标：`1.5 kVrms`、`60 s`。
- 项目爬电距离和电气间距目标：至少 `5 mm`。
- 只允许 U3 和 PS1 的功能结构跨越隔离区。
- 隔离带内禁止普通铜皮、走线、过孔和焊盘。
- 强度等级仍取决于污染等级、海拔、结构开槽和最终安规试验。

## 5. 铜皮与叠层

- GND 与 ISO_GND 独立铺铜，边界不得连接。
- ISO_GND 铜皮与焊盘采用花焊盘连接。
- B.Cu 优先作为 USB 区域连续 GND 参考面。
- M2 安装孔孔边到铜皮间距不得小于 `1.27 mm`；禁铺半径按
  `孔径半径 + 1.27 mm` 计算，`2.2 mm` 孔径对应 `2.37 mm`。
- 当前布线基线为 `generated/routing/USB_UART_Bridge_frozen.ses`，SHA-256
  `AA3BCD88D0543DB050E312FE63A81F5840888BC9388077DFE603535D5AF3846E`。
- 布线后 DRC 未连接项为 0；保留 4 条 J1 封装内部孔间距问题，以及连接器
  伸出板边导致的丝印重叠、覆盖铜皮和板边间距警告。
- 2 层 FR4 默认叠层不能自动保证 USB 90 ohm 差分阻抗。
- 若 2 层结构无法满足阻抗，应调整叠层或升级为 4 层。
- 阻抗控制需使用场求解器计算，并在首板通过 TDR/网络分析仪验证。

## 7. 发布要求

PCB 发布前至少需要：

- ERC 0 错误、0 警告。
- DRC 和原理图一致性检查通过。
- IPC-2152 载流复核完成。
- 电源回流和隔离回流检查完成。
- USB 差分阻抗与长度匹配检查完成。
- 所有嘉立创工艺例外有书面批准记录。
- Gerber、钻孔、叠层、坐标、BOM、STEP 和测试报告完整。
