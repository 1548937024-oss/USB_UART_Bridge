# Codex + KiCad USB-UART 演示

本目录用于建立一套可复现的 Codex 驱动 PCB 开发流程。演示电路采用
`CH343G`，实现隔离型 USB 2.0 转 3.3 V UART。

整个流程把需求、设计意图、脚本和 KiCad 工程文件都作为可版本控制的
工程资料。允许使用图形界面完成必要操作，但每个发布关口都必须能够通过
命令行重复执行。

当前原理图的网络标签优先落在实际连接走线上，不再为每个引脚固定拉出
`7.62 mm` 引线。同一局部区域内的同网引脚使用短实线连接；跨区域或会形成
交叉的连接使用同名网络标签。器件按照 USB 输入、桥接、隔离和输出四个功能区
排列，并通过旋转调整电流方向和走线方向。

原理图中的器件原点、全部引脚位置、走线端点、网络标签和 no-connect 均
必须落在 KiCad 默认的 `1.27 mm` 栅格上。生成脚本和验证脚本都会执行该检查。

原理图分为三个层次：

- 顶层 `USB_UART_Bridge.kicad_sch`：放置 USB-C、USB ESD、CC 下拉、UART 接口和
  VOUT 选择，并连接外部电气网络；USB 功能块整体位于左下区域。
- `Power.kicad_sch`：放置保险丝、隔离电源、隔离侧 LDO 及其去耦。
- `Communicate.kicad_sch`：放置 USB-UART 桥、数字隔离器和辅助状态电路。

跨图纸信号使用层次标签和图纸引脚连接。电源网络使用 `power` 库中的电源符号，
不使用普通网络标签。

`PWR_FLAG` 用于告诉 ERC 某些电源或地网络由外部连接器直接提供，避免把
USB-C、排针等无源接口误报为“电源没有驱动源”。它不是电源器件，也不会改变
`PWR_5V_RAW`、`PWR_5V_USB`、`PWR_VOUT_ISO`、`GND` 之间的实际连接关系。

### 电源域

- `PWR_5V_RAW`：USB-C VBUS。
- `PWR_5V_USB`：经过保险丝和 ESD 保护后的 USB 侧 5 V。
- `PWR_3V3_USB`：CH343G 的 V3 输出，用于 USB 侧逻辑和隔离器侧 1。
- `PWR_5V_ISO`：`IB0505LS-1WR3` 产生的隔离 5 V 电源。
- `PWR_3V3_ISO`：`AP2112K-3.3` 从隔离 5 V 产生的隔离 3.3 V 电源。
- `PWR_VOUT_ISO`：J2 第 2 脚的隔离输出，可通过 JP1 选择 `PWR_3V3_ISO` 或 `PWR_5V_ISO`。
- `GND`：USB 侧地。
- `ISO_GND`：隔离侧地。

JP1 的连接关系如下：

| JP1 引脚 | 网络 | 说明 |
| --- | --- | --- |
| 1 | `PWR_5V_ISO` | 选择隔离 5 V 输出 |
| 2 | `PWR_VOUT_ISO` | 连接到 J2 第 2 脚 |
| 3 | `PWR_3V3_ISO` | 选择隔离 3.3 V 输出 |

默认建议安装跳线帽将 JP1 的 2-3 脚短接，即输出 `PWR_3V3_ISO`。选择 `PWR_5V_ISO`
时，输出来自隔离电源模块。两个输出都在隔离侧，不能与 USB 侧地直接连接。

`Power` 图纸中的 `C7`、`C8` 分别与 `PS1` 的输入、输出引脚重合放置，
`C9` 与 `U4.5` 重合放置，`C10` 通过 `2.54 mm` 短线就近接到 `U4.5`。
`Communicate` 图纸中的 `D2` 旋转 `180°`，与横放的 `R5` 组成从左到右的
指示灯电流路径；`R6`、`R7` 也采用横放方向以缩短 UART 走线。

原理图按照 `AGENTS.md` 的 §10 可读性规范增加了模块边框、型号/参数/封装注释、
首页电源流向和修订表。页间信号只使用层次端口；电源和地使用统一网络符号。

该选择只改变 J2 第 2 脚的 `PWR_VOUT_ISO`，不会改变 TXD、RXD 的
3.3 V 逻辑电平。如果目标设备需要 5 V UART 逻辑，必须增加电平转换电路。

### 隔离架构

- 隔离栅位于 CH343G 与外部 UART 接口之间。
- `CH343G` 的最高 UART 数据率为 6 Mbps，满足 5 Mbps 以上要求。
- `U3 ISO7721D` 隔离 TXD 和 RXD，通道方向为一路输出和一路输入。
- `ISO7721D` 的最高数据率为 100 Mbps，远高于 UART 5 Mbps 的要求。
- `PS1 IB0505LS-1WR3` 提供 1 W 隔离电源，输入为 USB 侧 5 V，输出为隔离 5 V。
- `U4 AP2112K-3.3` 从隔离 5 V 产生隔离 3.3 V，为隔离器和外部接口供电。
- `GND` 与 `ISO_GND` 必须分开铺铜，隔离带内不得有铜皮、走线或过孔跨越。
- 隔离器件下方设置大于等于 5 mm 的爬电距离，并在装配图中标注隔离带。
- 建议在隔离带设置板边开槽，以提高爬电距离和隔离可靠性。
- 演示板隔离目标为 1.5 kVrms，生产前必须按最终安全等级完成耐压测试。

隔离输出负载按 `100 mA` 设计。`IB0505LS-1WR3` 和 `AP2112K-3.3` 都能覆盖
该电流，但不能把 USB 侧的 5 V 或 3.3 V 与隔离侧地直接连接。

USB 数据线没有经过数字隔离器，因为 CH343G 位于 USB 侧，隔离栅在其之后。
如果 USB D+/D- 也必须隔离，则需要改用 `ADuM3160` 或 `ADuM4160` 等 USB
隔离器，整体电源和信号架构需要重新设计。

当前桥接器上限为 6 Mbps。如果后续要求 10 Mbps 或 12 Mbps，可将 CH343G
替换为 `FT232H` 或 `FT2232H`，同时重新审核 USB、时钟、EEPROM 和隔离器功耗。

### UART 接口

| J2 引脚 | 信号 | 板卡侧方向 |
| --- | --- | --- |
| 1 | GND | 电源 |
| 2 | PWR_VOUT_ISO | 隔离 3V3/5V 参考电源输出 |
| 3 | RXD | 板卡输入 |
| 4 | TXD | 板卡输出 |

UART 网络按信号方向命名：

| 网络 | 含义 |
| --- | --- |
| `UART_TX_BRIDGE` | CH343G 的 UART TX 输出 |
| `UART_TX_ISO_IN` | 数字隔离器侧 1 输入 |
| `UART_TX_ISO_OUT` | 隔离后的 TXD 输出 |
| `UART_RX_ISO_IN` | 隔离侧 RXD 输入 |
| `UART_RX_ISO_OUT` | 数字隔离器侧 2 输入 |
| `UART_RX_BRIDGE` | 返回 CH343G 的 UART RX 输入 |

### P4. PCB 设置与布局

当前工程已提供 `scripts/generate_pcb.py`，布局数据来自
`design_intent.yaml` 的 `pcb_layout` 段。生成结果包括板框、安装孔、网络分配、
器件摆放、隔离带禁布区和基础设计规则。

制造和载流规范源为 `pcb_design_rules.yaml`，工程说明和未关闭项见
`docs/PCB_Design_Spec.md`。制造能力参考嘉立创公开工艺，载流与回流依据
IPC-2152 和 IPC-2221B 建立项目级设计目标。

生成命令：

```powershell
D:\KiCad10.0\bin\python.exe .\scripts\generate_pcb.py
```

输入：

- 网表。
- 板框和机械约束。
- 叠层、网络类和制造限制。

Codex 操作：

- 从已审核工程创建 PCB。
- 分配封装并同步网络。
- 根据机械边界放置连接器。
- 缩短 USB 差分对，并远离噪声节点。
- 将去耦电容放置在对应电源引脚附近。
- 在 PCB 上明确划分 USB 侧和隔离侧，禁止跨越隔离带布线。

通过条件：

- 板框与机械图一致。
- 所有封装都有有效 courtyard。
- USB、电源、UART、复位和 LED 网络连接正确。
- 连接器与安装孔不存在碰撞。
- 隔离带、爬电距离和开槽位置满足设计规则。

当前布局检查记录：

- 器件不越出板框，例外仅为 J1、J2、JP1 的机械或插拔部分。
- PCB 在最终输出中整体居中于 A4 图框，板内器件和机械结构的相对坐标不变。
- 器件物理外框无重叠；隔离器 `U3` 和隔离电源 `PS1` 跨隔离带，其他器件和铜结构不跨带。
- J2/JP1 顺时针旋转 90°，在最右侧上下并排，引脚朝板外，便于安装杜邦线。
- 4 个 M2 安装孔靠近板卡四角放置；左侧 J1 与 H1/H3 两个角孔同时存在且无 courtyard 重叠。
- PS1 第 1/2 脚位于 USB 侧，第 3/4 脚位于隔离侧，中间设置实际板槽；
  LS/SIP-4 封装将第 2/3 脚间距扩大到 `7.62 mm`，满足 `1.0 mm` 非金属槽要求。
- U2 紧邻 J1，用于优先缩短 USB D+/D- 的 ESD 泄放路径。
- J1 使用可加载的近似 3D 模型进行机械检查；机械发布前需替换为 XKB 官方 STEP
  或确认等效模型。
- PS1 已导入缩放后的近似 SIP-4 STEP 模型，机械发布前需替换为 YLPTEC 官方
  STEP 或完成尺寸等效性确认。
- 布线完成后 DRC 未连接项为 0；剩余 12 条固定项为 4 条 J1 封装内部孔间距和
  8 条 J2/JP1 伸出板边的丝印警告。
- USB-C 标准封装内部存在 4 个 NPTH 到 `GND` 焊盘 `A1/B12`、`A12/B1`
  的 0.1847 mm 间距检查项，低于当前板级 0.25 mm 配置，差 0.0653 mm；
  该项仍待板厂 DFM 或封装修改确认，不能视为已批准例外。
- 当前布局 DRC 除上述 4 个封装内部间距错误外，另有 8 条丝印边界警告，
  来源是 J2/JP1 为便于插拔而刻意伸出板外；无 courtyard 重叠。

### P5. 布线

当前工程已提供 `scripts/route_pcb.py`，默认复用冻结的 Specctra SES 基线
`generated/routing/USB_UART_Bridge_frozen.ses`，避免 FreeRouting 全局策略在
相同输入下产生随机结果。基线哈希为：

```text
AA3BCD88D0543DB050E312FE63A81F5840888BC9388077DFE603535D5AF3846E
```

生成命令：

```powershell
D:\KiCad10.0\bin\python.exe .\scripts\route_pcb.py
```

脚本会重建布局、导入冻结基线、把低于项目下限的走线统一到 `0.20 mm`，
补通 `PWR_VOUT_ISO` 和 `PWR_3V3_USB`，再铺设 `GND`、`ISO_GND` 和局部
`PWR_5V_ISO` 铜皮。若需要重新自动布线，先删除冻结 SES 文件，再运行同一脚本。

输入：

- 已完成布局的 PCB。
- 网络类和布线约束。

Codex 操作：

- 优先处理电源和地。
- 将 USB D+/D- 作为短差分对布线，并保证参考平面连续。
- 处理 UART 和低速控制信号。
- 使用 GND 铜皮，并检查过孔缝合。
- 通过脚本处理重复工作，关键高速决策仍保留人工审核。

通过条件：

- 不存在未布线连接。
- USB 差分对长度偏差满足工程限制。
- 电源和地回流路径连续。
- 不存在锐角走线或不必要的残桩。
- TXD 和 RXD 全部通过隔离器，未出现直连旁路。
- 5 Mbps UART 回环测试无误码，示波器测量波形无明显振铃。

### P6. 验证

输入：

- 已完成的 PCB。
- 原理图网表和设计规则。

Codex 操作：

- 运行带原理图一致性检查的 DRC。
- 重新填充铜皮并再次运行 DRC。
- 生成 3D 渲染并检查机械配合。
- 审核报告并修复问题，不以屏蔽方式绕过问题。

通过条件：

```powershell
kicad-cli pcb drc --schematic-parity --refill-zones --save-board `
  --format json --severity-all --exit-code-violations `
  -o reports/drc.json USB_UART_Bridge.kicad_pcb
```

- 未排除 DRC 错误数为 0。
- 原理图与 PCB 不存在一致性差异。
- 铜皮填充为最新状态。
- 渲染结果符合装配方向要求。
- `GND` 与 `ISO_GND` 不存在短路，隔离耐压测试满足设计要求。

### P7. 制造输出

输入：

- 已审核的 PCB 和制造工艺。

Codex 操作：

- 生成 Gerber、钻孔、坐标和装配资料。
- 生成用于机械集成的 STEP 文件。
- 归档发布时使用的全部设置和报告。

通过条件：

- Gerber 和钻孔层完整。
- Gerber 查看器能够正确打开钻孔和板框。
- Gerber 与源文件版本可以追溯。
- 从干净目录可以重新生成发布包。

### P8. 发布与变更控制

输入：

- 制造包。
- 测试结果和已知限制。

Codex 操作：

- 冻结版本。
- 记录 ERC、DRC 结果和生成文件哈希。
- 下一版本只能从已发布基线继续修改。

通过条件：

- 源文件、报告和制造输出一起提交。
- 干净环境下可以复现相同发布文件。
- 任何人工修正都记录在变更说明中。

## 实现方法

推荐采用三层结构：

1. **人工审核的源数据**：需求、框图、关键器件、叠层和机械约束。
2. **Codex 辅助的设计操作**：网表/BOM 生成、封装分配、布局辅助、
   重复布线、检查和导出。
3. **KiCad 验证**：ERC、DRC、原理图一致性、铜皮重填、3D 渲染、
   Gerber 和 STEP 导出。

完全自动的器件选型和全自动布线不作为发布关口。它们可以生成初始方案，
但正式设计仍然需要电气、机械、EMC、热设计和制造审核。
